# Narutinho API

API simples com Express para o Entregável 2.1.

## Como rodar localmente

```bash
npm install
node index.js
```

## Endpoints

| Rota | Descrição |
|------|-----------|
| GET /nomes | Lista de nomes completos |
| GET /folha-menores | Personagens da Folha menores de idade |
| GET /kekkei-genkai | Quantidade com kekkei genkai |
| GET /chakras-jonin | Chakras dos Jonin |
| GET /chakra-stats | Total, média, maior e menor chakra |
| GET /chunin-razao-media | Razão chakra-idade média dos Chunin |
| GET /razao-extremos | Maior e menor razão chakra-idade |

## Bruno

A pasta `bruno-collection` contém a coleção para testar no Bruno. Abra a pasta como coleção no Bruno.
